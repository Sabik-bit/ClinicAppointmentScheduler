Clinic Appointment Scheduler - Starter Project

This is an early C# console version of the Clinic Appointment Scheduler.

Current starter structure:
- Patient class
- Doctor class
- Appointment class
- Program.cs creates sample objects and displays them

To run on macOS in VS Code:
1. Open the ClinicAppointmentScheduler folder in VS Code.
2. Open Terminal > New Terminal.
3. Run:
   dotnet run

This is a starter only. Continue developing and committing your own genuine progress.
